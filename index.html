Frequently Asked Questions

Where is my writing stored?

Only on your Mac. Bird Writer never connects to the internet, and nothing you write is ever sent anywhere.

Does it sync across devices?

No — everything stays local by design. To move your work between Macs, use “Save Project…” to export a single project file (.bwt) and open it on the other Mac.

How is my work backed up?

Bird Writer saves automatically as you write and keeps generational backups. You can also save your entire workspace as a .bwt project file at any time.

How do I get my text out?

Use File → Export… to save any board or a single box as plain text (.txt).

Can an AI assistant help with my manuscript?

Yes. A project is a single .bwt file you can hand to an assistant like Claude or ChatGPT — see Writing with an AI assistant for the guide to give it first.
